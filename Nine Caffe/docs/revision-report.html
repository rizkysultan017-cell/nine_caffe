1. What this revision is

The old page was a generic card stack with a placeholder menu, low-contrast text, and motion that hid content until JavaScript ran. This revision keeps the warm, local, late-night positioning and rebuilds the surface around the supplied menu and logo.

The direction is Dusk Coffee Ledger: warm paper, deep espresso green, burnt clay, and one butter-yellow signal. The page reads like a printed menu under a low lamp: oversized Fraunces type, ruled lines, numbered sections, and mixed paper/forest surfaces instead of identical rounded cards.

What stayed Indonesian copy, cafe data, WhatsApp-first ordering, static-site simplicity, and every demo disclosure. No framework, no build step, no runtime dependency.

5. Motion and accessibility

Motion. One easing family: --ease-out, --ease-in-out, --ease-drawer. Press 120ms, hover 160ms, state 200ms, drawer 280ms, reveal 420ms. Only transform and opacity animate. Hover transitions are gated behind @media (hover: hover) and (pointer: fine). ?motion=off and prefers-reduced-motion remove marquee, parallax, reveal movement, and drawer slide without hiding content.

Accessibility. Skip link, visible focus ring, semantic landmarks, labelled controls. The order sheet and lightbox are real dialogs with focus trap, Escape close, focus restoration, inert background, and scroll lock. Live regions announce cart changes, copy results, and empty states. Mobile inputs stay at 16px; touch targets are at least 44px.

6. Ordering flow

Pilih menu → tambah ke keranjang → buka “Lihat pesanan” → atur jumlah dan catatan → isi nama, jenis pesanan, nomor meja bila perlu → salin atau kirim.

Because the live WhatsApp number is not supplied, Kirim via WhatsApp copies the exact order text and shows a toast; Salin pesanan does the same on demand. The order text is built by cafe-core.js, so every path produces the same result.
